# 智賬

兩人共同記帳的 PWA。前端純靜態（GitHub Pages 託管），雲端即時同步使用 Firebase（Auth + Firestore）。

線上版：https://ha1948.github.io/zhizhang/ （加入主畫面即可當 App 使用）

## 版面架構

底部導覽列：**Books｜Accounts｜＋｜Reports｜Settings**（再點一次當前分頁會回到本月）

## 功能

### ＋ 記一筆
- 支出／收入／轉帳（成員互轉，可加手續費，手續費自動另存為付款人全額負擔的支出）
- 金額可手動輸入或用內建計算鍵盤（＋−×÷、00/000、先乘除後加減）
- 類別為固定格子選擇器；點日期開自製日曆（日→月→年層級跳轉，附昨天/今天快捷）
- 誰付的／誰要分攤（預設兩人平分，可自訂各自金額，含即時檢查）
- 備註不限字數；編輯頁底部顯示最後更新時間
- 「儲存」與「儲存並繼續」（後者存完重設為平分繼續記）

### Books
- 日曆模式：月曆＋收支圓點，點日期看當日明細
- 列表模式：收支／轉帳／全部篩選、月收支結餘、依日期分組
- 點記錄直接進編輯；左滑（桌面用滑鼠拖）出刪除鈕，刪除需二次確認
- 右上搜尋：全歷史關鍵字搜尋（類別、備註、成員、金額）
- 點月份標題可直接跳任意年月

### Reports
- 月／年／自訂範圍（最近 7/30/90 天、全部、自訂起迄）
- 支出／收入／轉帳三種報表：圓餅圖＋排行榜（金額、佔比、總計、日均）
- 年檢視附每月趨勢長條圖，點長條跳到該月
- 排行榜點類別進入該類別明細清單，可直接編輯／刪除

### Accounts（成員結算）
- 兩人各自總花費（應負擔的分攤金額）、誰需要給誰多少
- 「結清」一鍵自動新增今天的轉帳記錄歸零
- 月份統計：可逐月切換或跳任意年月

### Settings
- 誰付的（成員名稱）、類別管理（新增／編輯；「編輯」模式下 − 刪除＋拖曳排序）
- Language：中文 ⇄ English 整介面切換
- 雲端同步（見下）、匯出／匯入 JSON、匯出 CSV（Excel 可開）

### 其他
- 深色模式（跟隨系統）、可安裝 PWA、離線可用（連網自動補同步）
- 版本更新自動套用（重開 App 一次即生效，Settings 底部顯示版本號）

## 雲端同步（多帳本模式）

- 每本共享帳本有自己的**建立者**與**成員名單**；任何人都可建立自己的帳本
- 使用需 Email＋密碼登入並完成信箱驗證
- 憑 8 碼配對碼申請加入某本帳，由**該帳本建立者**在 App 內「同意／拒絕／封鎖」
- Firestore 規則以帳本根文件（owner / members / blocked）授權：
  非成員讀寫一律拒絕；被封鎖者連申請都會被規則擋下
- 衝突解法：同一筆記錄以更新時間較新者為準
- 舊版（無根文件）帳本會在重連時自動升級，重連者成為建立者

## 開發

```bash
python3 -m http.server 8642 --directory zhizhang
```

- `index.html` / `style.css` / `app.js` — 介面與全部邏輯（含 i18n）
- `sync.js` — Firebase 同步層（ES module，載入失敗不影響本機功能）
- `firebase-config.js` — Firebase 公開金鑰（安全性由 Firestore 規則把關）
- `sw.js` — Service worker（改版時需遞增 CACHE 版本號）
- `manifest.json` / `icon*` — PWA 安裝資訊

部署：push 到 `main` 即由 GitHub Pages 自動發布（約 1 分鐘）。
