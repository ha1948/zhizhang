# 智賬

兩人共同記帳的 PWA 網頁 App。純前端、無後端，資料存在瀏覽器 localStorage。

## 版面架構

底部導覽列（左至右）：**Books｜Accounts｜＋｜Reports｜Settings**

## 功能

- **＋ 記一筆**（整頁表單）：支出／收入／轉帳三種；列式欄位（金額、類別、誰付的、誰要分攤）；
  點日期可直接改；備註為大輸入框不限字數；
  內建計算鍵盤（＋−×÷、00/000、先乘除後加減）；「儲存」與「儲存並繼續」
- **誰要分攤**：點列開彈窗 — 勾選成員、平均分攤（預設）或自訂各自金額（含即時餘額檢查）
- **轉帳**：成員之間互轉（誰轉出→轉給誰），計入兩人結算；
  可開啟「手續費」開關（金額＋誰付的），手續費自動另存為該成員全額負擔的一筆支出
- **Books 日曆模式**：月曆＋收支圓點標記，點日期看當日明細
- **Books 列表模式**：收支／轉帳／全部篩選、月收支結餘、依日期分組
- **搜尋**：右上放大鏡，全歷史關鍵字搜尋（類別、備註、成員、金額）
- **Reports**：分類報表 — 月／年／自訂範圍（最近 7/30/90 天、全部、自訂起迄）、
  支出／收入切換、圓餅圖＋排行榜（金額、佔比、總計、日均）
- **Accounts（成員結算）**：兩人各自「總花費（應負擔）」與「實付」、誰需要給誰多少；
  按「結清」自動新增一筆今天的對應轉帳記錄，餘額歸零
- **Settings（條列式）**：誰付的（自訂兩人名字）、類別管理（新增／編輯／刪除，
  自訂名稱與 emoji，同步到記帳頁）、匯出／匯入 JSON 備份（依 id 合併去重，可在兩台手機間同步）
- 支援深色模式（跟隨系統）、可安裝到手機主畫面、離線可用

## 本機執行

```bash
python3 -m http.server 8642 --directory zhizhang
```

然後開 http://localhost:8642 。

## 部署（讓兩個人都能用）

把 `zhizhang/` 資料夾內容放上任一靜態網站託管（GitHub Pages、Netlify、Cloudflare Pages…），
必須是 **HTTPS** 才能安裝 PWA 與啟用離線功能。

手機上用 Safari／Chrome 開啟網址 →「加入主畫面」即可像 App 一樣使用。

> 注意：資料存在各自裝置的瀏覽器中，兩台手機不會自動同步。
> 可定期用「設定 → 匯出資料」傳給對方，對方「匯入資料」即可合併。

## 檔案結構

- `index.html` — 頁面結構（Books/Accounts/Reports/Settings + 記帳整頁 + 對話框）
- `style.css` — 簡約風格樣式（方圓形按鈕、深色模式）
- `app.js` — 全部邏輯（記帳、計算鍵盤、分攤、日曆、搜尋、報表、結算、備份）
- `manifest.json` / `sw.js` — PWA 安裝與離線快取
- `icon.svg` / `icon-192.png` / `icon-512.png` — App 圖示
